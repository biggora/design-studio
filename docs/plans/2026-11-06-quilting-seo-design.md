# Quilting SEO implementation

Source: owner-approved 6 November 2026 quilting audit and request to implement the two design pages plus links from Gifts for Hobbyists. Baseline US Search Console: both URLs indexed, zero impressions/clicks through 3 November; no ranking or conversion conclusion is justified yet.

Use the existing runtime site configuration rather than changing marketplace titles or adding brand-specific conditions to the engine. `studio.designPages` supplies two optional slug-keyed editorial profiles: title (brand appended by the renderer), H1, meta description, visible introduction, mockup alt, buying information and related design links. Profiles without a matching active design do not create pages. Existing pages retain their previous rendering when no profile matches. Artwork identities, canonicals, marketplace URLs, frozen OG/Pinterest images and prices retain their existing source.

`giftPages[].designLinks` supplies a small heading, introduction and links. Resolve all configured links through the active catalog facade before rendering; omit missing, hidden, duplicate or self links. Show the gift block only on the first unfiltered page. Put it after the results and pagination, before FAQ, so the catalog stays easy to reach on mobile. Both design pages receive permanent mutual links before the generic related-print rail.

The two alternatives were editing marketplace-backed title/description fields (would couple SEO to listing identity and still leave no independent meta description) and hardcoded page conditions (would break the white-label configuration convention). Optional runtime profiles are the smallest existing-pattern extension that supports the approved independent fields.
